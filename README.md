# SM4 Machine Learning Differential Distinguisher

## Description

This repository presents a Python implementation of a **machine learning–based differential distinguisher** for the SM4 block cipher. The project investigates the application of neural networks to distinguish ciphertext pairs generated by reduced-round SM4 from randomly generated ciphertext pairs, following the standard **real-vs-random** methodology widely adopted in modern differential neural cryptanalysis.

Developed as part of an undergraduate research project on **Machine Learning Assisted Cryptanalysis of Symmetric-Key Block Ciphers**, the implementation provides a complete experimental pipeline comprising SM4 encryption, differential dataset generation, neural network training, evaluation across multiple round configurations, and visualization of experimental results.

## Implementation

The project consists of three primary stages.

### 1. SM4 Cipher Implementation

The cipher implementation follows the official **GB/T 32907-2016** specification and includes:

- Key expansion
- Round key generation
- SM4 S-box substitution
- Linear transformation
- Configurable reduced-round encryption

The implementation has been verified using the official SM4 test vector.

### 2. Differential Dataset Generation

Training data is generated using the standard **real-vs-random differential distinguisher** framework.

For every experiment:

- A random encryption key is generated.
- Plaintext pairs are constructed using a fixed input difference.
- Reduced-round SM4 encryption is performed.
- Ciphertext pairs are labelled as either genuine differential pairs or random pairs.

The generated dataset is then used for supervised learning.

### 3. Neural Distinguisher

The generated ciphertext pairs are used to train a multilayer perceptron classifier.

Rather than relying on manually derived differential characteristics, the classifier learns statistical relationships directly from the ciphertext data to distinguish reduced-round SM4 outputs from random data.

Performance is evaluated over increasing numbers of SM4 rounds to observe how statistical distinguishability diminishes as diffusion increases.

## Methodology

For a fixed one-bit plaintext input difference `Δ` (least significant bit of the final byte):

- **Real Pair (Label = 1)**
  - Generate a random encryption key `K`
  - Generate a random plaintext `P₀`
  - Compute `P₁ = P₀ ⊕ Δ`
  - Encrypt both plaintexts under the same key for **R** rounds to obtain `(C₀, C₁)`

- **Random Pair (Label = 0)**
  - Generate a random encryption key `K`
  - Generate a random plaintext `P₀`
  - Encrypt `P₀` to obtain `C₀`
  - Replace `C₁` with an independent random 128-bit value

### Feature Representation

Each training sample consists of **256 binary features**:

- 128 bits representing `C₀ ⊕ C₁`
- 128 bits representing `C₀`

Providing both the ciphertext difference and the absolute ciphertext enables the classifier to capture subtle statistical biases present in reduced-round encryption.

### Classifier

The implementation uses Scikit-learn's `MLPClassifier` with:

- Three hidden layers (256 → 128 → 64)
- ReLU activation
- Early stopping
- 20,000 training samples
- 5,000 testing samples for each round configuration

## Experimental Results

The distinguisher is evaluated across increasing numbers of SM4 rounds using **classification accuracy** and **ROC-AUC** as performance metrics.

Running the experiment generates:

- `results.csv` containing the evaluation metrics for each round configuration.
- `sm4_distinguisher_results.png` visualizing classifier performance across different numbers of SM4 rounds.

### Interpretation

The selected single-bit input difference produces a strong, learnable statistical footprint during the initial rounds of SM4, allowing the neural distinguisher to classify ciphertext pairs with high accuracy for low-round configurations.

As the number of rounds increases, SM4's substitution and diffusion layers effectively eliminate exploitable statistical structure, causing classifier performance to converge towards random guessing. This behaviour is consistent with the expected diffusion properties of SM4 and aligns with its current public security status, for which no practical distinguishing or key-recovery attacks are known against the full 32-round cipher.

## Running the Project

### Clone the Repository

```bash
git clone https://github.com/<your-username>/SM4-ML-Differential-Distinguisher.git
cd SM4-ML-Differential-Distinguisher
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Verify the SM4 Implementation

```bash
python3 sm4.py
```

### Run a quick sanity check (fast, ~2 seconds)
python3 -c "
from distinguisher import train_and_eval
acc, auc = train_and_eval(rounds=1, n_train=2000, n_test=500)
print('1-round:', acc, auc)
" 

### Execute the Experiment

```bash
python3 distinguisher.py
```

This performs the complete round sweep and generates the experimental results.

### Generate the Performance Plot

```bash
python3 plot_results.py
```

This creates the visualization from the generated experimental data.
